# Portfolio Ummi Khoiroh (React + Vite)

## Jalankan lokal
    npm install
    npm run dev        # buka http://localhost:5173

## Build produksi
    npm run build && npm run preview

## Deploy ke Vercel
1. Push ke GitHub  2. vercel.com > Add New > Project > Import repo
3. Framework: Vite (otomatis), klik Deploy.

Warna ada di `src/index.css` (variabel `:root`). Teks ID/EN ada di `src/App.jsx` (objek `T`).
